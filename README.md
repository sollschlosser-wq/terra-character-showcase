# Terra 角色设计作业

[打开展页](https://sollschlosser-wq.github.io/terra-character-showcase/)

当前页面使用示例角色「苔芽 MOSS」和配套试听素材，供前期确认展页结构。

## 更新页面

- 在 `index.html` 修改角色名称、介绍、章节和媒体路径。
- 把角色图、视频封面、短片和音频放入 `assets/`。保留相对路径，方便从本地和 GitHub Pages 打开。
- `style.css` 管理页面样式与动效，`showcase.js` 管理章节导航、造型切换和播放状态。
- 本地可直接打开 `index.html`。将更新推送到 `main` 后，GitHub Pages 会从仓库根目录重新发布。
